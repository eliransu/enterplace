No keys yet. Make a keys file with the open source CLI and give it to the chart as a Secret:
  enterplace key new admin --team platform --admin --keys enterplace.keys.yaml
  kubectl create secret generic enterplace-keys --from-file=enterplace.keys.yaml
  helm upgrade {{ .Release.Name }} <chart> --reuse-values --set keys.existingSecret=enterplace-keys
The Secret seeds new volumes only: a replica that already has a keys file keeps it.
