Glossary

The words used on this site and in the docs, each in a few sentences.

AI gateway
One program that sits between a company's AI tools and the model providers. Tools send requests to the gateway, and the gateway sends them on. What is an AI gateway
Alias
One model name that is served from several deployments, for example the same model at two providers. The gateway picks a deployment for each request and falls back to another when one fails.
Audit log
The record of every request and every admin action. In Enterplace it is one JSON line per event, holding who asked, the model, the decision, the rule and the cost. It holds no prompt or answer text.
Budget
The most a team, a person, a key or a model may spend in a period. When it is reached, further requests are refused until the period starts again or someone raises the number.
Coding agent
A tool that writes and changes code by calling a model many times in one task, such as Codex, Claude Code, Cursor or Gemini CLI. It reads files around it and sends parts of them in prompts.
Coverage
How much of the company's AI use goes through the gateway. Enterplace's coverage report counts requests per person and tool, and names people who hold a key and have sent nothing.
Decision ID
The identifier Enterplace gives each request. It is returned in the X-Enterplace-Decision header and repeated in every refusal message, so a person can quote it and an admin can find the record.
Fail closed
When a safety step cannot run, the request is refused instead of let through. Enterplace refuses every request while it cannot write the audit log.
Guardrail
A check on the text of a request or an answer. It can block the request, mask what it found, or only warn. Enterplace has built-in detectors for secrets and personal data and can call outside services.
Hash chain
Each audit record holds a fingerprint (a hash) of the record before it. Change, remove or reorder a record and every fingerprint after it stops matching, so the change shows.
Key
The secret a tool sends to prove who is calling. A provider key is issued by OpenAI, Anthropic and the like, and with a gateway it stays inside the gateway. A Enterplace key is issued to one person or one workload.
Kill switch
A stop for a person, a team, a key, a model or everyone, set with one command and a reason. It works at once and needs no policy change.
MCP
Model Context Protocol. The way agents call tools on other systems, such as creating an issue or querying a database. An MCP server offers the tools, and an MCP client, usually an agent, calls them.
Observe mode
A setting for the whole policy in which nothing is blocked. Every request from a known key is forwarded, and what a rule would have refused is recorded as would_refuse.
Policy
The file that says who may use which models and tools, with which limits and guardrails. In Enterplace it is one YAML file kept in version control.
Provider
The company or server that runs the model: OpenAI, Anthropic, Azure OpenAI, Amazon Bedrock, Vertex AI, Gemini, or a server of your own such as Ollama or vLLM.
Rate limit
A cap on how fast requests may arrive, in requests or tokens per minute. It protects against loops and against one caller using up a shared quota.
Refusal
What a caller gets when policy stops a request: an error with a code such as budget_exceeded, the cause, what to do, and a decision ID.
Residency
A rule that requests may only go to deployments in named regions. In Enterplace you label each deployment with its region, and a request with nowhere allowed to go is refused.
Self-hosted
You run the software in your own network or cloud account. Prompts and answers go only to the providers you chose, and the vendor of the software sees none of it.
Shadow mode
A trial for one limit or one guardrail. Until the date you set, it records what it would have done and changes nothing. From that date it is enforced.
SIEM
The system a security team uses to collect and search logs from every other system, such as Splunk or Microsoft Sentinel.
Token
The unit providers count and bill: a piece of a word. A request costs the tokens sent plus the tokens answered, each at the model's price.
Workload
Anything that calls a model and is not a person: a service, a CI job, an agent. It gets a key of its own, with a name such as svc-billing.
