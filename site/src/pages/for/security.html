Use casesFor security

"What left the company, and can you prove it?"

That question lands on security. Today the honest answer is that prompts go from laptops straight to providers, on shared keys, with no record on your side. Gantry puts one checked, recorded path in between.

What you get

A record of every decision
Allowed or refused, written before the request is forwarded, chained by hash. It holds no prompt text, answer text, keys or matched secrets.
Guardrails you can try first
Secrets and personal data blocked or masked, on requests, answers and MCP tool calls. Each runs in shadow until a date you set.
Keys that stay put
Provider keys never leave the gateway. Gantry keys are shown once and stored as a SHA-256 hash, and one can be revoked without touching anyone else.
A stop button
A kill switch on a person, a team, a key, a model or everyone, with a reason, recorded.

The console's Audit log page, on test data. Refused and blocked decisions are the only colored rows.

What you can answer afterwards

Each answer comes from the audit log or a command, so it can be checked by someone other than you.

QuestionWhere the answer comes from
Which AI tools are in use, and by whom?gantry audit coverage: requests per person and tool, and key holders who sent nothing.
Has a secret gone into a prompt?The request log, filtered by guardrail finding such as aws_access_key or database_url.
Is the record complete and unchanged?gantry audit verify, with the last hash you kept elsewhere.
Who changed the policy, and who approved it?Policy versions in the console, with a second admin's approval and a dry run against recent requests.
Can the SIEM have all of it?Export to Splunk, Datadog, Elastic, Microsoft Sentinel or object storage. Enterprise In the open source edition, ship the file with Vector, Fluent Bit or the OpenTelemetry Collector.

Where it stops

  • Gantry is pre-1.0 and has not yet had an independent security audit.
  • It sees only what is sent through it. Block direct provider access at the network if you need to be sure.
  • Built-in guardrails match plain text. Encoded, split or translated text is not found.
  • Whoever can write the policy, the keys file or the audit file controls them. Protect those like provider keys.
