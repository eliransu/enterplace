By what you run

Coding agentsClaude Code, Codex, Copilot, Cursor, Gemini CLI and the rest, each developer under their own name and budget. With the table of what was run against Gantry. Cloud and production agentsServices and agents in your cloud, each with its own key, limit and stop button. MCP toolsYour MCP servers behind one endpoint, with allow lists, approvals and tool pins. Local and self-hosted modelsOllama, vLLM and LM Studio, on-prem or air-gapped, under the same rules as hosted models. Regulated data and residencyRequests kept in the regions a rule allows, personal data masked, and a record you can verify. Cost controlSpend per person, team and model, budgets you try before you enforce, and a forecast for each.
