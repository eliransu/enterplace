By what you run

Claude Team and EnterpriseEvery Claude Code user in the organization with one managed settings block pasted into claude.ai. Nothing installed on laptops. Coding agentsCodex, Claude Code, Copilot, Cursor, Gemini CLI and the rest, each developer under their own name and budget. With the table of what was run against Enterplace. Cloud and production agentsServices and agents in your cloud, each with its own key, limit and stop button. MCP toolsYour MCP servers behind one endpoint, with allow lists, approvals and tool pins. Local and self-hosted modelsOllama, vLLM and LM Studio, on-prem or air-gapped, under the same rules as hosted models. Regulated data and residencyRequests kept in the regions a rule allows, personal data masked, and a record you can verify. Cost controlSpend per person, team and model, budgets you try before you enforce, and a forecast for each.

RoleThe question you are askedWhat you get
SecurityWhat left the company, and can you prove it?Guardrails on requests, answers and tool calls, and a hash-chained record of every decision.
PlatformHow do 300 people get model access without provider keys on laptops?One endpoint for every provider, and a policy file that is checked in CI.
FinanceWho spent this, and will the budget last the month?Spend per team, person and model, with a forecast for each budget.
Engineering leadersCan we roll out coding agents without losing track of them?Two settings per developer, a name on every session, and a budget per team.
