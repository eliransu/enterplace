An open source gateway. A license adds what a larger company needs.

The gateway, the console and the command line are open source under Apache 2.0, for any number of people. Gantry Enterprise is the same binary in the same image, with features that a signed license key turns on.

Open source

Apache 2.0. One binary on files, or several replicas on Postgres. No license key and no account.

  • Keys per person and workload, gantry login through OpenID Connect or SAML, JWTs from your identity provider
  • Policy as one file, checked by gantry check, with observe mode and kill switches
  • The hash-chained audit log and the command that verifies it
  • Guardrails, the MCP gateway, budgets, rate limits and caching
  • Routing, retries and fallbacks across the major providers and local servers
  • The admin console with single sign-on, teams and roles
  • Prometheus metrics and OpenTelemetry traces

Gantry Enterprise

Everything in the open source edition, plus the features the license names.

  • Console members with roles, and SCIM 2.0 provisioning from Okta and Microsoft Entra ID
  • Audit export to a SIEM: Splunk, Datadog, Elastic, Microsoft Sentinel, OTLP, a webhook, or object storage
  • Alerts on budgets, errors and guardrail blocks, to Slack, Teams, PagerDuty or email
  • Audit retention with a legal hold
  • Export to LLM observability tools
  • The device agent, for coverage on laptops
  • Docker Compose, Helm, Terraform and Cloudflare deployment templates
How the license works

There are no prices on this site.

How the license behaves

It was designed so that a license problem can never become an outage.

Checked offline
The license is signed and checked against a public key built into the binary. The check never uses the network, so it works the same in an air-gapped network.
Nothing calls home
No usage data is sent to the Gantry project.
It never stops model traffic
Whatever the license says, the gateway keeps serving, governing and recording requests.
Source you can read
The Enterprise code is in the repository under a commercial license, there to read and audit. Running it in production needs a valid key.
WhenWhat happens
Before the expiry dateEverything the license names is on.
Up to 30 days after itEverything stays on. A warning is printed at start.
After the 30 daysEnterprise features are off. Model traffic is still served.
