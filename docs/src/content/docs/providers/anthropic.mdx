A provider of `kind: anthropic` serves Anthropic's messages API. Claude Code and the Anthropic SDKs reach it through Gantry's `POST /v1/messages`.

## Example

```yaml title="gantry.policy.yaml"
version: 1
providers:
  - name: anthropic
    kind: anthropic
    url: https://api.anthropic.com
    key_env: ANTHROPIC_PROVIDER_KEY
    models: [claude-sonnet-5-5, claude-haiku-5-5]
rules:
  - name: everyone
    principals: { any: true }
    models: [claude-sonnet-5-5, claude-haiku-5-5]
```

<Aside type="caution">
Name the key variable something other than `ANTHROPIC_API_KEY`. Claude Code reads that variable for its own key, which must be a Gantry key.
</Aside>

## Behavior

| Item | Behavior |
|---|---|
| Routes | `POST /v1/messages` and `POST /v1/messages/count_tokens`, forwarded as their original bytes, streams included. |
| Key | Sent as `x-api-key: <key>`. |
| Headers | `anthropic-version`, `anthropic-beta`, every other `anthropic-*` header and every `x-claude-code-*` header pass unchanged. |
| Query | `beta=true` or `beta=false`, once. Anything else is refused by name with `unknown_query`. |
| Chat completions | Refused with `wrong_route`, unless the provider sets `accept_chat: true`. |
| Cost | `count_tokens` requests are free and reserve nothing under a budget. |

## Chat clients

Set `accept_chat: true` and chat completions requests for this provider's models are translated to messages, sent, and the answer translated back. A translated request carries `anthropic-version: 2023-06-01`.

```yaml
providers:
  - name: anthropic
    kind: anthropic
    url: https://api.anthropic.com
    key_env: ANTHROPIC_PROVIDER_KEY
    models: [claude-sonnet-5-5]
    accept_chat: true
```

See [Translation](/routing/translation/) for what is carried across and what is refused with `untranslatable`.
