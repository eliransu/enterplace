The open source gateway needs no license. The `enterplace` binary in the image `ghcr.io/eliransu/enterplace` is the enterprise build: without a license key it runs the open source features only, and a valid key unlocks the enterprise features it names.

## Two licenses in one repository

Enterplace is one repository with two licenses, the way LiteLLM is:

- Everything outside `enterprise/` (the gateway, the console, the command line, the deploy files and the docs) is under the MIT License, and the root `LICENSE` file says so at the top, as LiteLLM's does. You can build it with `cargo install --path crates/enterplace-cli` and run it without a key.
- `enterprise/` holds the enterprise features under the Enterplace Commercial License (`enterprise/LICENSE`). Its source is there to read and audit. Running it in production needs a valid Enterplace license key, and it may not be redistributed or changed to get around the license check.

The open source crates never import `enterprise/`. The enterprise crate plugs into them through their extension hooks.

## Set it

The license is one line of text. Give it to `enterplace` in one of two ways:

```sh
export ENTERPLACE_LICENSE='eyJjdXN0b21lciI6...'          # the token itself
export ENTERPLACE_LICENSE_FILE=/etc/enterplace/license       # or a file that holds it
```

Set one, not both. In Kubernetes, put the token in a Secret and pass it as `ENTERPLACE_LICENSE`. Restart the gateway after you change it.

At start, the gateway says once what the license unlocks:

```text
License lic_8f2 for Acme: scim, siem, 50 seats, until 2027-11-13.
```

To see it at any time, without the token:

```sh
enterplace license show --keys enterplace.keys.yaml
```

It prints the customer, the features, seats used of allowed, the expiry date and whether the license is in its grace period.

`GET /healthz` shows it too, under `license`: `state` (`valid`, `grace`, `lapsed` or `missing`), `customer`, `id`, `features`, `expires` and `grace_days`. Never the token.

## Nothing calls home

The license is signed by Enterplace and checked against a public key built into the binary. The check never uses the network, so it works the same in an air-gapped network.

## At expiry

| When | What happens |
|---|---|
| Before the expiry date | Everything the license names is on. |
| Up to 30 days after it | Everything stays on. A warning is printed at start. |
| After the 30 days | Enterprise features are off. Model traffic is still served. |

A license never stops model traffic: the gateway keeps serving, governing and recording requests whatever the license says. A feature the license does not unlock answers with the code `license_required` and says what to do.

Set the renewed license and restart to turn the features back on.

## Seats

Seats count people: the distinct names in the keys file. When more people hold keys than the license has seats, the gateway prints a warning at start. It does not block anyone. Ask for more seats, or revoke keys that are no longer used.

## When the gateway refuses to start

A license that is set and cannot be checked stops the start, with the cause:

- **not an Enterplace license**: the token is cut short or has extra text. Paste it again, on one line.
- **not signed by Enterplace**: the token was changed after it was issued. Paste it exactly as you received it, or ask for a new one.
- **both ENTERPLACE_LICENSE and ENTERPLACE_LICENSE_FILE are set**: unset one.

To run the open source features only, unset `ENTERPLACE_LICENSE` and `ENTERPLACE_LICENSE_FILE`.
