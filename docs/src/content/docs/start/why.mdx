Your people already use AI tools. Developers run Claude Code, Codex and Cursor. Other teams call model APIs from scripts and internal apps. Each tool talks to a provider on its own, so the company has no single place to look.

Gantry is that place. It is one program that sits between your tools and the model providers. Tools send their requests to Gantry, and Gantry sends them on. Because every request passes through it, Gantry can show you what is happening and, when you choose, apply your rules.

## Five questions

| Question | A plain example | Answered by |
|---|---|---|
| Who uses which AI tools? | Three teams adopted three coding tools this year and nobody kept a list. | [Step 1: See](/start/step-1-see/), then [Step 2: Know](/start/step-2-know/) for names |
| What does it cost? | The provider invoice gives one total per account. It does not say which team or tool spent it. | [Step 1: See](/start/step-1-see/) |
| Can you cap it and stop it? | An agent retries the same task all night. A key is pasted into a public issue. | [Step 3: Limit](/start/step-3-limit/) |
| What leaves the company? | Someone pastes a config file into a prompt, and the file holds a database password. | [Step 4: Protect](/start/step-4-protect/) |
| Can you prove it? | A customer or an auditor asks who used which model last quarter, and how you know the record is complete. | [Step 5: Prove](/start/step-5-prove/) |

## What the first step asks of you

Step 1 is one container (or one binary), your existing provider keys, and a settings change in each tool so it points at Gantry. It runs in observe mode: every request from a key you issued is forwarded, and nothing your people do today is blocked.

You decide when to go further. Each step is one change on top of the last, and each one works without the next.

## What Gantry does not do

- It sees the requests that are sent through it. A tool that still calls a provider directly stays invisible until you point it at Gantry. The [coverage report](/governance/coverage/) lists people who hold a key and have sent nothing.
- Its audit log holds who asked, which model, the decision and the cost. It holds no prompt or answer text.
- Developers on Claude Team or Enterprise seats cannot route through a gateway. For them Gantry has a [watch setup](/integrations/claude-team/) that covers steps 1 and 2.
