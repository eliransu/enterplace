LangChain's chat models for OpenAI and Anthropic are built on the official SDKs, so they reach Gantry by base URL, with a Gantry key in place of a provider key. Plain calls, streaming and tool calling work as they do against the provider.

## Send a request

<Tabs syncKey="lang">
<TabItem label="Python">

```bash
pip install langchain-openai langchain-anthropic
```

```python
from langchain_anthropic import ChatAnthropic
from langchain_openai import ChatOpenAI

gpt = ChatOpenAI(model="gpt-4o-mini", base_url="http://127.0.0.1:8080/v1", api_key="gantry_...")
print(gpt.invoke("Say hello.").content)

claude = ChatAnthropic(model="claude-sonnet-4-6", base_url="http://127.0.0.1:8080", api_key="gantry_...", max_tokens=256)
for chunk in claude.stream("Say hello."):
    print(chunk.content, end="")
```

</TabItem>
<TabItem label="JavaScript">

```bash
npm install @langchain/openai @langchain/anthropic
```

```js
import { ChatOpenAI } from "@langchain/openai";
import { ChatAnthropic } from "@langchain/anthropic";

const gpt = new ChatOpenAI({ model: "gpt-4o-mini", apiKey: "gantry_...", configuration: { baseURL: "http://127.0.0.1:8080/v1" } });
console.log((await gpt.invoke("Say hello.")).content);

const claude = new ChatAnthropic({ model: "claude-sonnet-4-6", apiKey: "gantry_...", anthropicApiUrl: "http://127.0.0.1:8080", maxTokens: 256 });
for await (const chunk of await claude.stream("Say hello.")) process.stdout.write(chunk.content);
```

</TabItem>
</Tabs>

`ChatOpenAI` takes the address with `/v1`; `ChatAnthropic` takes it without. Instead of passing them, you can set `OPENAI_BASE_URL` and `OPENAI_API_KEY`, or `ANTHROPIC_BASE_URL` and `ANTHROPIC_API_KEY`, as for the [SDKs](/integrations/sdks/).

## Tools and refusals

`bind_tools` (`bindTools` in JavaScript) declares function tools as the SDK does, so a rule's [tool permissions](/governance/tool-permissions/) apply. A refusal comes back as the SDK's own error, with Gantry's code:

```python
import openai

try:
    gpt.bind_tools([run_shell]).invoke("Clean the disk.")
except openai.PermissionDeniedError as e:
    print(e.code)  # tool_not_allowed
```

## Tested

`scripts/langchain_check.py` starts a mock provider and `gantry serve`, then drives LangChain through it: a plain call, a streamed call and a tool call with `ChatOpenAI` and `ChatAnthropic`, a model the rule does not allow (`model_not_allowed`) and a function tool it does not allow (`tool_not_allowed`). With `--js` it runs the same checks with LangChain.js.

```bash
cargo build -p gantry-cli
uv run --with langchain-openai --with langchain-anthropic python3 scripts/langchain_check.py target/debug/gantry --js
```

Last run on 2026-11-14 with langchain-openai 1.8.0, langchain-anthropic 1.7.10 and langchain-core 1.8.0 (Python), and @langchain/openai 1.8.4, @langchain/anthropic 1.6.5 and @langchain/core 1.4.1 (Node 25). It needs network access to install them, so it is not part of `scripts/ci.sh`.
