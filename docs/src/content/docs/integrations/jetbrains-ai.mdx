JetBrains AI Assistant takes a third-party provider of kind OpenAI-compatible. With Enterplace there and an Enterplace key, chat and the features you assign to Enterplace's models send their prompts through Enterplace. It needs no JetBrains AI subscription.

<Aside type="tip" title="Before you start">
You need a running Enterplace and an Enterplace key. `enterplace start` gives both in one command and prints the key as `export ENTERPLACE_KEY=...`: see the [Quickstart](/getting-started/quickstart/). No provider key yet? Put the model `enterplace-demo` in place of the model in the examples below: Enterplace answers it itself, free. After your first prompt, **Requests** in the console shows it with the key's name, the model and the cost.
</Aside>

## Setup

<Steps>

1. Open **Settings | Tools | AI Assistant | Providers & API keys**.
2. Under **Third-party AI providers**, set **Provider** to **OpenAI-compatible**.
3. Enter the Enterplace key in **API Key** and Enterplace's address with `/v1` in **URL**, for example `http://127.0.0.1:8080/v1`.
4. Check **Tool calling**, then **Test Connection** and **Apply**.
5. Under **Models Assignment**, choose Enterplace's models for **Core features** and **Instant helpers**. Until you do, they are used in AI Chat only.

</Steps>

Requests go to `POST /v1/chat/completions`. AI Assistant lists the models from `GET /v1/models`, which returns the models the key may use.

## What Enterplace governs

- AI Chat with an Enterplace model, and every feature assigned to Enterplace's models.

## What Enterplace does not see

- A feature the assigned models do not support. AI Assistant sends its prompt and context to the JetBrains AI service instead.
- Code completion and next edit suggestions. They use JetBrains' Mellum model unless **AI Completion** is set to an OpenAI-compatible provider with a fill-in-the-middle model. Enterplace serves `POST /v1/completions` for models on an `openai` provider; this setup is untried.
- Junie, which takes a JetBrains AI subscription or an OpenAI or Anthropic key, and no custom URL.
- Anything an IDE Services or JetBrains Central admin routes elsewhere.

<Aside type="note">
This follows JetBrains' AI Assistant 2026.3 documentation (custom models, models settings, BYOK). It was not run through Enterplace.
</Aside>
