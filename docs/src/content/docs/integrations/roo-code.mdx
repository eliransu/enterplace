Roo Code is configured like [Cline](/integrations/cline/), in its settings panel in VS Code. It reaches Enterplace over OpenAI's chat completions API or Anthropic's messages API, with an Enterplace key in place of a provider key.

<Aside type="tip" title="Before you start">
You need a running Enterplace and an Enterplace key. `enterplace start` gives both in one command and prints the key as `export ENTERPLACE_KEY=...`: see the [Quickstart](/getting-started/quickstart/). No provider key yet? Put the model `enterplace-demo` in place of the model in the examples below: Enterplace answers it itself, free. After your first prompt, **Requests** in the console shows it with the key's name, the model and the cost.
</Aside>

## Setup

<Tabs>
<TabItem label="OpenAI Compatible">

| Setting | Value |
|---|---|
| API Provider | OpenAI Compatible |
| Base URL | Enterplace's address with `/v1`, for example `http://127.0.0.1:8080/v1` |
| API Key | The Enterplace key |
| Model | The model as the policy names it |

Requests go to `POST /v1/chat/completions`. Roo Code uses native tool calling only, so the model must support tools. Roo Code's documentation gives no example base URL, so the `/v1` ending follows the OpenAI convention. A 404 `unknown_route` from Enterplace means the path is wrong.

</TabItem>
<TabItem label="Anthropic">

| Setting | Value |
|---|---|
| API Provider | Anthropic |
| Anthropic API Key | The Enterplace key |
| Use custom base URL | Checked, with Enterplace's address and no `/v1`, for example `http://127.0.0.1:8080` |

Requests go to `POST /v1/messages`, where refusals use Anthropic's error shape.

</TabItem>
</Tabs>

## What Enterplace governs

- Every model request Roo Code makes with this provider.

## What Enterplace does not see

- Telemetry, sent to PostHog by default with the VS Code machine ID. Turn it off in Roo Code's settings.
- Codebase indexing. Its embedder is a separate setting with its own provider and key, and the vectors go to the Qdrant instance you choose. To send embeddings through Enterplace, set **Embedder Provider** to OpenAI Compatible with Enterplace's `/v1` address: Enterplace serves `POST /v1/embeddings` for `openai`, `azure`, `gemini`, `vertex`, `cohere`, `watsonx` and `bedrock_converse` providers.

<Aside type="note">
This follows Roo Code's documentation. Roo Code's repository was archived in May 2026. It was not run through Enterplace.
</Aside>
