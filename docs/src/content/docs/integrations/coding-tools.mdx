A coding tool goes through Gantry when it lets you set a base URL and a key for an OpenAI, Anthropic or Google Gemini API. This page lists each tool Gantry has a guide for, the route it uses, and what it sends elsewhere whatever you configure.

| Tool | Route on Gantry | Stays outside Gantry | Run against Gantry |
|---|---|---|---|
| [Claude Code](/integrations/claude-code/) | `/v1/messages` | Telemetry unless turned off | Yes |
| [Codex](/integrations/codex/) | `/v1/responses` | | Yes |
| [OpenCode](/integrations/opencode/) | `/v1/chat/completions` | | Yes |
| [Qwen Code](/integrations/qwen-code/) | `/v1/chat/completions`, `/v1/responses` | Usage statistics, model catalog | Yes |
| [Kilo Code](/integrations/kilo-code/) | `/v1/chat/completions`, `/v1/responses`, `/v1/messages` | Autocomplete, telemetry | Yes (CLI) |
| [GitHub Copilot](/integrations/github-copilot/) | `/v1/chat/completions`, `/v1/responses`, `/v1/messages` | Inline suggestions, embeddings, utility tasks by default | Yes (CLI) |
| [Gemini CLI](/integrations/gemini-cli/) | `/v1beta/models/<model>:streamGenerateContent` (Google's Gemini API) | Usage statistics, telemetry | Yes |
| [Cursor](/integrations/cursor/) | `/v1/chat/completions`, from Cursor's servers | Tab completion | No |

"Run against Gantry" means the tool's real client was run headless against a local Gantry and a mock provider, and the audit records were checked. No run used a real model provider.

## Tools without a guide

These tools offer no setting that sends their model requests to a gateway of your own, in their public documentation:

- **Windsurf** (now Devin Desktop). Models come from Cognition's catalog, and the admin controls offer an allowlist and defaults, not an endpoint. The only custom endpoint documented is a `models.json` file for federal air-gapped deployments.
- **Amazon Q Developer** and its successor **Kiro**. Both call AWS's own service endpoints, reachable over a VPC endpoint, with no custom model endpoint. The Q IDE plugins reach end of support on April 30, 2027.

## Which tools reach Gantry

Each request record carries the caller's user agent. `gantry audit coverage` counts requests per person and tool, and names key holders who sent nothing. See [Coverage](/governance/coverage/).

<Aside type="note">
A tool that sends its SDK's default user agent shows up as that SDK: Copilot CLI as `OpenAI/JS`.
</Aside>
