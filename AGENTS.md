# Conventions for agents working in this repository

This is the private commercial edition of Gantry. It depends on the open source crates in the sibling `gantry` repository and adds product features by implementing the traits those crates expose.

- Product work packages (marked P in the plan) go here.
- Never move code from here into the open repository, and never add a license check to the open repository.
- All rules in the open repository's `AGENTS.md` apply here too.
